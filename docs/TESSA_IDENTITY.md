# Tessa — Canonical Visual Identity

Status: **LOCKED — Tessa V1**

Approved: 2026-09-28  
Approved candidate: **Option 3 — friendly automotive-tech representative**

## Canonical identity rule

The approved Option 3 face is the visual identity of Tessa, the Thompson Transportation Technologies website assistant.

Routine website assets must be created by cropping, resizing or compressing the approved master. Do **not** regenerate a new face for normal UI work.

For future expressions, animation, 3D or video work, the approved master must be supplied as the identity reference so facial identity remains consistent.

## V1 website avatar

The live website uses a 128 × 128 WebP crop derived directly from the approved Option 3 image. It is embedded in `lib/brand/tessaAvatarData.js` so the chatbot cannot silently fall back to a different portrait because of a missing static asset.

## Character direction

Tessa is friendly, confident, professional and automotive-technology oriented. She should feel approachable enough for a retail customer while credible enough for dealership, fleet and technical conversations.

## Change control

Any change to Tessa's face/identity should be treated as a new version (for example Tessa V2) and explicitly approved before replacing V1.
