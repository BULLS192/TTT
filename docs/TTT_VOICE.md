# TTT Voice & Editorial Standard

TTT should sound like a competent automotive technology integrator explaining a real vehicle, not a generic marketing agency.

## Write like this
- Start with the vehicle, the problem, or the tradeoff.
- Prefer concrete nouns: factory amplifier, warning chime, cellular plan, rear camera, circuit protection.
- Explain why a detail changes the recommendation.
- Use short sentences when the point is simple.
- Say what TTT will preserve, change, test, or document.
- Distinguish consumer, dealership and fleet use cases when the workflow is materially different.

## Avoid this
- Empty verbs: elevate, transform, unlock, revolutionize.
- “Seamless,” “cutting-edge,” “best-in-class,” or “premium” without an explanation.
- Repeating “integrated solution” when the actual system can be named.
- Three adjectives where one specific noun works.
- Repeated four-card layouts just because a template supports them.
- Public roadmap language: “coming soon,” “foundation active,” “as we grow,” “future platform.”
- Invented client work, quotes, certifications, partner status, performance numbers or years of experience.

## TTT page test
Before publishing, ask:
1. Could this paragraph appear on a home-automation, IT-consulting or solar company website unchanged? If yes, rewrite it.
2. Does the page contain at least one detail that only makes sense for this vehicle technology topic?
3. Is the customer told what changes the scope or recommendation?
4. Are unfinished internal features hidden rather than advertised?
5. Is any claim about experience, customers, brands or results verifiable?

## Preferred rhythm
Mix formats. Use narrative, technical diagrams, comparison tables, process lines, question lists and real project photography. Do not force every page into eyebrow → headline → four cards → dark section → CTA.
