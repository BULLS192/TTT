# TTT canonical logo asset

The approved Thompson Transportation Technologies logo was supplied by the project owner on September 10, 2026 and is the canonical TTT logo for all website and digital-platform work.

## Non-negotiable brand rule

Do **not** substitute, redraw, reinterpret, regenerate, simplify, or replace this logo unless the project owner explicitly requests a logo redesign.

The approved mark contains:

- the stylized coupe / TTT vehicle silhouette;
- the first integrated `T` in black;
- the second and third integrated `T` characters in deep blue;
- `THOMPSON` in black;
- `TRANSPORTATION TECHNOLOGIES` in deep blue.

`ttt-logo.svg` is the web derivative used by the site. When a higher-resolution/vector master becomes available, replace the embedded raster inside that SVG while retaining the exact approved artwork and this filename so application code does not need to change.
